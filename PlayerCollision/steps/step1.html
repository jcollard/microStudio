Step 1: Getting Started

Before implementing collision detection, you need a project with the enemy spawning system in place. This lesson builds on the foundation from the Enemy Spawner lesson.

Choose Your Path

Option 1: Clone the Starter Project (Recommended)

Start with a pre-configured project that has all the prerequisites already set up. This is the fastest way to begin.

Starter Project: https://microstudio.io/jocolloman/spawningenemies8/

The starter project includes:

  • Complete wave-based enemy spawning system
  • Object pooling for efficient memory usage
  • Player movement and shooting mechanics
  • All prerequisite systems ready to go

Option 2: Continue from Your Own Project

If you completed the Enemy Spawner lesson, you can continue with your existing project. Just make sure it meets the requirements below.

Requirements Checklist

Your project must have the following before proceeding:

  • Wave-based enemy spawning - Enemies spawn in progressively larger waves
  • A player object with position properties (player.x, player.y)
  • Player dimensions - Width and height for collision bounds
  • The enemies table with enemy objects that have position and size
  • Enemy isDestroyed property to track active enemies
