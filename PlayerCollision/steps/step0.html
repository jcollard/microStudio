Step 0: Welcome

In this lesson, you'll build a complete game loop with player-enemy collision, lives, and game states.

What You'll Build

Press Enter to start, Arrow keys to move, Space to shoot

Key Concepts

  • Game States — title, playing, game over
  • isDestroyed Pattern — apply familiar pattern to the player
  • Frame-based Timers — respawn delays
  • Complete Game Loop — title → playing → game over → title

Prerequisites

  • Completed Enemy Spawner lesson
  • Working wave-based enemy spawning
  • Player movement and laser firing
  • Understanding of isDestroyed pattern from enemies

By the end, you'll have a fully playable game with proper start and end states!
